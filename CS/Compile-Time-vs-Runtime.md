
# Compile-Time

## 1. 컴파일이란?

컴파일은 개발자가 작성한 소스 코드를 컴퓨터가 실행할 수 있도록 다른 형태의 코드로 변환하는 과정이다.

## 2. 컴파일 과정

```text
소스 코드
    ↓
컴파일러
    ↓
C# (IL 코드) 또는 Java (바이트코드)
    ↓
런타임 환경
```

C#과 Java는 일반적으로 컴파일할 때 바로 기계어로 변환하는 것이 아니라, 중간 코드로 변환한다는 공통점이 있다.

## 3. 컴파일 과정에서 하는 일

컴파일러는 코드를 변환하는 일만 하는 게 아니라 여러 가지 검사도 수행한다.

| 작업 | 설명 |
|---|---|
| 문법 검사 | 작성한 코드가 언어의 문법에 맞는지 확인 |
| 타입 검사 | 변수와 값의 자료형이 올바른지 확인 |
| 코드 변환 | 소스 코드를 중간 코드 등으로 변환 |
| 오류 검출 | 실행 전에 발견할 수 있는 오류를 알려줌 |

### C#으로 예를 들면

```csharp
int number = "Hello";
```

=> int 변수에 문자열을 대입하려 했기에 컴파일 오류가 발생한다.

## 4. 컴파일과 컴파일 타임의 차이

| 용어 | 의미 |
|---|---|
| 컴파일 (Compile) | 소스 코드를 다른 형태의 코드로 변환하는 과정 |
| 컴파일러 (Compiler) | 컴파일 작업을 수행하는 프로그램 |
| 컴파일 타임 (Compile Time) | 컴파일이 이루어지는 시점 |
| 컴파일 오류 (Compile Error) | 컴파일 과정에서 발견되는 오류 |

## 5. 핵심 정리

컴파일은 개발자가 작성한 코드를 실행 가능한 형태로 변환하면서 문법과 타입 등의 오류를 검사하는 과정이다.

또한 컴파일에 성공했다고 해서 프로그램 실행 중 오류가 발생하지 않는다는 뜻은 아니다.

=> 런타임 오류가 발생할 수 있다.

# Runtime

## 1. 런타임이란?

런타임은 프로그램이 실행되는 시점 또는 실행 중인 상태를 의미한다.

컴파일 타임이 소스 코드를 검사하고 변환하는 시점이라면, 런타임은 컴파일된 프로그램이 실제로 실행되는 시점이다.

## 2. 런타임 과정

```text
소스 코드
    ↓
컴파일러
    ↓
C# (IL 코드) 또는 Java (바이트코드)
    ↓
런타임 환경
    ↓
프로그램 실행
```

C#과 Java는 일반적으로 컴파일된 중간 코드를 런타임 환경에서 처리하여 실행한다.

| 언어 | 런타임 환경 | 역할 |
|---|---|---|
| C# | .NET 런타임 (CLR) | IL 코드를 실행하고 메모리 및 예외 등을 관리 |
| Java | JVM (Java Virtual Machine) | 바이트코드를 실행하고 메모리 및 예외 등을 관리 |

런타임 환경은 JIT 컴파일 등을 통해 중간 코드를 기계어로 변환하여 실행할 수 있도록 한다.

## 3. 런타임에서 하는 일

런타임 환경은 프로그램이 실행되는 동안 여러 가지 작업을 수행한다.

| 작업 | 설명 |
|---|---|
| 코드 실행 | 컴파일된 코드를 실제로 실행 |
| 메모리 관리 | 프로그램에서 사용하는 메모리를 관리 |
| 가비지 컬렉션 (GC) | 더 이상 사용하지 않는 객체의 메모리를 자동으로 회수 |
| 예외 처리 | 실행 중 발생한 예외를 처리할 수 있도록 지원 |
| JIT 컴파일 | 실행 중 중간 코드를 기계어로 변환 |

## 4. 런타임 오류란?

런타임 오류는 컴파일에는 성공했지만 프로그램이 실행 중 발생하는 오류를 의미한다.

### C#으로 예를 들면

```csharp
int a = 10;
int b = 0;

Console.WriteLine(a / b);
```

=> 문법과 자료형에는 문제가 없으므로 컴파일은 성공한다.

=> 하지만 프로그램 실행 중 0으로 나누려고 하면 `DivideByZeroException` 예외가 발생한다.

그러니까 컴파일러가 모든 실행 중 오류를 미리 발견할 수 있는 것은 아니다.

## 5. 컴파일 타임과 런타임의 차이

| 구분 | 컴파일 타임 (Compile Time) | 런타임 (Runtime) |
|---|---|---|
| 의미 | 소스 코드를 컴파일하는 시점 | 프로그램이 실행되는 시점 |
| 주요 작업 | 문법 검사, 타입 검사, 코드 변환 | 코드 실행, 메모리 관리, 예외 처리 |
| 오류 | 컴파일 오류 | 런타임 오류 |
| 오류 예시 | 자료형 불일치, 문법 오류 | 0으로 나누기, null 참조 |
| C# | C# → IL 코드 | .NET 런타임에서 실행 |
| Java | Java → 바이트코드 | JVM에서 실행 |

## 6. 핵심 정리

런타임은 컴파일된 프로그램이 실제로 실행되는 시점이다.

C#과 Java는 런타임 환경을 통해 중간 코드를 실행하며, 실행 중 메모리 관리와 예외 처리 등의 작업이 이루어진다.

또한 컴파일에 성공했다고 해서 프로그램이 반드시 정상적으로 실행되는 것은 아니다.

=> 컴파일 타임에는 발견되지 않았던 오류가 런타임에 발생할 수 있다.
